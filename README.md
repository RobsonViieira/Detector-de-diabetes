# Detector de Diabetes com scikit-learn

Este projeto usa um modelo de machine learning para prever se uma pessoa tem diabetes com base em características clínicas. Ele utiliza a biblioteca `scikit-learn` e os dados públicos do Pima Indians Diabetes Database.

## Requisitos

- Python 3.7+
- Bibliotecas:
  - pandas
  - numpy
  - scikit-learn
  - matplotlib

Você pode instalar as dependências com:

```bash
pip install -r requirements.txt
